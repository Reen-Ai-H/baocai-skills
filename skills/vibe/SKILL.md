# 包菜的 vibe 知识视频

这是**用 Claude 做知识视频的完整经验手册**：审美标准 + 工作流程 + 技术管线 + 协作规矩。
目标：**商业片的完成度，非商业的用途**——开头留住人，全程不空、不拖、不吵，看完觉得「爽」，而且真学到了东西。

个人 IP 署名「包菜的AI宇宙」只在用户要求时出现在封面或片尾小字。

## 0. 一句话原则

**每讲一个新知识点，画面或声音必须真的发生一次变化；讲完立刻用可感的例子证明它。**
视频语言为主，文字为辅；循序渐进；不写反思/说教段落。

## 1. 这条生产线解决什么

| 类型 | 画幅 | 声音气质 |
|---|---|---|
| 动效科普短片 | 竖屏 9:16 优先发抖音 | 卡点、起伏、有「爽」的转场 |
| 音乐知识片 | 横屏 16:9 | 讲解页轻、歌曲段响；代码演奏动机 |
| 声音/助眠科普 | 16:9 母版，构图留 9:16 安全区 | 可全 ASMR 化；约 −21 LUFS |
| MV / 情绪片 | 按用户 | 以给定 BGM 卡点 |

全平台发布时：**先做横版母版，关键主体居中，预留竖裁安全区**。

## 2. 审美标准

### 好的
1. 开头就抓人（约 3 秒内抛出问题/游戏/悬念）。
2. 讲清楚优先于文字少。
3. 循序渐进；知识点与「享受段」交替。
4. 满而且动，同时有焦点。
5. 炫、高级、好懂；每段有记忆点。
6. 真实可信：原图、出处、可核数据。
7. 讲什么就示范什么；示范时配乐让开。
8. 声音有情绪也有呼吸。
9. 收尾闭环或把问题交给评论区。

### 不行
空、静、幻灯片、开头慢、自编口号、反思说教、难看吉祥物、拖或赶、吵、硬切、照搬参考、重绘名作、改掉夸过的东西、编造出处。

### 默认采用（用户另说时以用户为准）
无旁白、无人声；画面和配乐代码生成；画幅按发布平台定，不默认竖屏；字幕少、大、关键词标红，完整出现后至少停 1 秒；片名卡 ≤ 2 秒；素材用原图并注明出处。

### 不需要
旁白配音（除非用户要）、片中大片名卡、进度条、下集预告、结尾说教总结、把资料全部讲完、写实人物和复杂真实感渲染、无限循环的评审。

### 冲突时
用户本次原话 > 历史原话 > 独立审片 > 本 skill 默认。停留 ≠ 静止；满 ≠ 多；讲清楚优先。

## 3. 和 Claude / Claude Code 协作

1. 需求原话进 `docs/` 或 `msg*.txt`，协调方不加戏。
2. 开工前一页计划；选项给 3 个或表格勾选。
3. 先可播放短样片（约 10s–1min），通过后再全片。
4. 反馈逐字存档：原话 / 理解 / **保留项** / 修改项。
5. 精确数字照做。
6. 独立审片最多一轮；「直接发给我」则跳过。
7. 完成即同步，卡住即说，不等人催。
8. 用户说「不要用本地 skill」时全部停用。

## 4. 工作流程

Brief → 拆参考 → 知识点+例子/歌单 → 风格系统 → 单一时间轴 → 短样 → 反馈 → 全片 → QC → 交付 → 沉淀。

结构公式（可裁剪）：
```
钩子 → 短标题(≤2s) → 先认识 → 奖励例子 → 知识点↔例子循环 → 闭环/尾奏
```

沉淀时：通用做法写回 craft；喜好/否决写回本 skill。**不要把某一片的具体做法写进正文。**

## 5. 画面

讲解页持续微动；近静止全片约 <5–10%，任一段不超过约 20%。
招牌强调：红圈 + 压暗。案例用原图并在上面分析。竖屏避开底部约 25% 与右侧按钮列。

## 6. 声音

- 通用：切点落强拍；大时刻前收空；示范时配乐让开；常规约 −14 LUFS。
- 音乐知识片：取动机简化编曲；旋律比伴奏高 2–4 dB；三层轨道共用播放线。
- ASMR/助眠：可用触发音替代合成配乐；双耳交替慢；一次一个焦点；约 −21 LUFS；禁突然变响。

## 7. 技术栈

Remotion + Python 时间轴/混音；免版权或代码合成音效；QC 用联系表 + 响度 + 近静止。

## 8. 交付

成片路径、相对原话的改动清单、实测数字、试听提醒、版权待决、竖+横封面、约 5 个标题备选、下一步只一件事。

## 9. 出片前四问

0–3 秒钩子？近静止/空白？配乐呼吸与让位？保留项还在吗？
