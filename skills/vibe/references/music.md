# 音乐科普子类（和弦 / 节奏等）

## 结构

```
冷开场(≈4s) → 标题(≈2s) → 认识最常见的东西(≈10s) → 第一首歌奖励(≈8s)
→ 知识点(≤25s) → 歌 → … → 回顾快切 → 黑底标题
```

- 章内排歌：最熟 → 最新 → 最意外；相邻章风格在抒情 / 律动间交替。
- 同一首歌全片最多 2 次，第二次换段落。
- 可放 1 个有出处的数据彩蛋。

## 引用歌曲

- **不照搬原曲编曲**：只取最有辨识度的动机，配为知识点服务的简化编曲。
- 旋律从简谱录入；没有可靠谱子的歌不进片。
- 每次换和弦：和弦重音 + 根音低音 + pad + 底鼓；正在讲的音单独放大。
- 进歌前收空半拍到一拍，强拍碎玻璃切入；歌后回讲解页可加白闪。
- 底部三层轨道：旋律卷帘（含简谱数字）、和弦色块、鼓点，共用播放线。

## 响度参考

- 讲解页约 −19 dB，歌曲段约 −14.5 dB，母带约 −14 LUFS。
- 旋律比伴奏高 2–4 dB。

## 画面

- 纸面讲解：暖灰纸、墨字、朱红强调；几何图形表达音程（半音比例）。
- 歌曲页：全屏风格化插画，不用专辑封面。
