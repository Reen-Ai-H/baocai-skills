## 1. 画面质感

| 层 | 做法 |
|---|---|
| 角色 | 全身每个像素块占 4 个屏幕像素，近景占 6 个，落在固定网格上；12 fps。走路循环约 6 fps |
| 场景纹理 | 每个像素块占 2 个屏幕像素 |
| 光、雾、雨 | 全分辨率、平滑，24 fps |
| 字幕、手机、物品卡 | 全分辨率，保持清晰 |
| 收尾 | 高光泛光、色调压缩、暗角、颗粒 |

**不要整体移动或缩放人物图。** 呼吸、头动、发丝按位移场重采样回网格。

**跳切推近用整数比例裁切**（4/3、3/2），放大后方块仍是方的。任意比例缩放会把像素格拉花。

## 2. 素材和生图

- 需要抠图的素材用品红底，需要替换的区域（窗外、屏幕）用品青，提示词里写明。
- 拼图按空白自动切块，从左到右、从上到下。每格之间留宽缝，尤其走路循环。
- 编辑已有拼图（比如换嘴型）比重新生成更能保持同一张脸。
- 全身图和近景要用保留细线的像素化，普通的去杂点会吃掉五官。近景的调色板只从近景图提取，否则皮肤暗部偏色。
- 分镜可以让生图模型出九宫格做参考，由导演决定怎么拍，不直接上屏。

## 3. 嘴、眨眼、镜像

**嘴。** 每种表情配 4 张：底图、半张嘴、张嘴、闭眼。合成时：

```python
# 只动嘴部区域里真正有差异的像素，眉眼不动
skin = 肤色掩码(底图)
x0, y0, x1, y1 = bbox(skin)
if region == 'mouth':
    y0 += int((y1 - y0) * .60)     # 脸的下方 40%
else:                              # 眨眼
    y1 = y0 + int((y1 - y0) * .56) # 脸的上方 56%
diff = abs(变体 - 底图).sum(-1) > .22
mask = diff & 区域(x0, y0, x1, y1)
mask = 外扩一圈(mask) & 人物不透明区域
输出 = 底图; 输出[mask] = 变体[mask]
```

先把变体按头部轮廓对齐到底图。对不齐时，用底图的包围盒切块，不要各切各的。

**嘴型驱动。** 语音音量取 8 Hz 包络，映射到闭、半、张三档。

**镜像。** 剪辑表里按镜头标记，并指定镜像轴。要回看三件事：
- 图上的文字（招牌、胸牌）有没有反；
- 发分、光的方向；
- 同一人物在相邻镜头里的造型是否一致。

## 4. 剪辑表

```python
class S:  # 取旧素材的一段
    (label, 素材起点, 素材终点, speed=1.0, punch=None, pic=None, look=None, flip=None)
class N:  # 新拍的镜头
    (label, 时长, fn)      # fn(u, seed) -> 帧
EDL = {场: [S(...), N(...), ...]}
VO  = {场: [(镜头标签, 台词 key, 是否入画, 延迟, 尾巴)]}
```

- 镜头长度可以由配音决定：有台词的镜头 = 语音长度 + 延迟 + 尾巴。总时长和各场起点全部算出来，不手写。
- 字幕、手机事件都按素材时间写，经表映射后自动跟随。
- 拟音也一样：记录旧场景的所有音效点，再按表重映射。这样重剪不需要手工重铺声音。
- 环境和音乐手工按新时间轴铺，它们跨镜头。

## 5. 配音

**上集所用平台的情况（以平台文档为准，开工前先探测）：**
- 账号并发只有 1 条，同时请求会返回 429。顺序生成，失败重试。
- 表演权重：台词约 3，旁白约 2（默认 1 时情感偏平）。
- 中文可用音频标签：`[叹气] [吸气] [抽泣] [轻笑] [喘息] [喊叫] [停顿]`。

**一口气录制：**

1. 把一段连续台词拼起来送合成，表演说明写整段的情绪走向（“第一句发抖，第二句一路往上，中间不能平下来”）。
2. 按字数比例估切点，在估计点附近找最近、最长的静音（窗口 20 ms，静音阈值 `max(峰值 × .05, .004)`，至少 60 ms）。评分：`|距离| − 1.5 × 静音长度`。
3. 切开后的文件接后处理。

**后处理：**

```
ffmpeg -af "silenceremove=start_periods=1:start_threshold=-40dB:start_silence=0.03,
  areverse,silenceremove=start_periods=1:start_threshold=-40dB:start_silence=0.08,areverse,
  silenceremove=stop_periods=-1:stop_duration=0.25:stop_threshold=-38dB:stop_silence=0.18"
```

- 预期长度按 4.4 字/秒估。超过 1.15 倍预期长度才用 `atempo`，最多 1.15。
- 上集的合成语速：连续录制的段落 1.0–1.2，单独生成的句子最高 1.25。它和 `atempo` 会叠加，听着赶就退回来拉长镜头。
- 情绪最重的句子和旁白不用 `atempo`，宁可拉长镜头。
- 每句按有声部分归一化音量，再按角色给增益。

## 6. 混音

| 空间 | RT | 湿 | 低通 | 反射 |
|---|---|---|---|---|
| 街边 | .14 | .07 | 9500 | 22 |
| 球场 | .2 | .08 | 9000 | 60 |
| 实验室 | .32 | .14 | 8500 | 14 |
| 办公室 | .26 | .1 | 7000 | 12 |
| 大棚市场 | .22 | .08 | 9000 | 45 |
| 楼梯间 | 1.15 | .34 | 7500 | 26 |
| 硬墙客厅 | .42 | .2 | 8500 | 10 |
| 帐篷内 | .1 | .03 | 8000 | 6 |

**状态：**

| 状态 | 处理 |
|---|---|
| 画外、背对 | 带通 180–3600 Hz，音量 ×.7，湿度 ×2.2 |
| 喊到破音 | `tanh(x × 2.2)` |
| 虚弱 | 带通 120–6500 Hz，湿度 ×.7 |
| 喘着说 | 句间垫呼吸录音 |
| 内心独白 | 不加空间，略提 70–260 Hz，贴耳 |

**让位：** 有人说话时，环境和音乐压低约 55%，拟音只压一点。

**静默段：** 用单独的包络把所有声音床压掉，只放呼吸这一路。上集黑场约 −47 dB。

**credits：** 名单由脚本生成。手工追加的段落（比如配音）会在重跑时丢失，要写进生成脚本。

## 7. 响度和母带

**混音后：**
1. 量整段响度，算到目标（上集 −13.6 LUFS，编码后约 −14）的增益。
2. 软限幅，不要硬削。

**真峰值是编码后才知道的。** 上集混音文件采样峰值只有 −3.4 dB，真峰值已到 −0.3 dB，编码成 256k AAC 后 −0.1 dB，已经贴顶。下次目标留到 −1 dB 左右，这个目标在上集没有验证过。

**分享版另量。** 上集实测：

| 来源 | 编码 | 真峰值 |
|---|---|---|
| 母版 AAC 再压 | 96k（实际分享版约 98k） | +3.5 dB |
| 混音 wav 直接压 | 96k | +2.8 dB |
| 混音 wav 直接压 | 128k | +1.4 dB |
| 混音 wav + `alimiter=limit=0.6` | 128k | −0.1 dB |

所以分享版要从混音 wav 压，不要从母版 AAC 再压；码率至少 128k，并先限幅。真峰值过 0 dB，在一些播放器上会削波。

**高潮要用瞬时和短时 LUFS 量。** 上集把电弧压低后，我按 RMS 判断它仍是全片最响，这个判断是错的。按 K 加权实测，通过版的情况是：

| 位置 | 内容 | 瞬时 / 短时 LUFS |
|---|---|---|
| 3:35.5 | 争吵的喊叫 | 瞬时 −3.5 |
| 2:49.5 | 工程段（发泡胶、封窗） | 短时 −6.4 |
| 4:23.1 | 城市断电电弧 | 瞬时 −6.8 |

用户已通过这一版。下次调混音时，应把高潮的电弧也放进这张表里比。

## 8. 渲染的坑

- `render | tail` 会吞掉崩溃，渲染脚本用 `set -o pipefail`，渲完检查时长是否等于时间轴。
- 多进程缓存要原子写：写临时文件再 `os.replace`，否则会读到半个文件（`UnpicklingError`）。
- 总装先拼纯视频轨再挂总音频。各场带声音直接拼会有偏移和响度跳变。上集偏移约 −17 ms。
- 时间轴用实际帧数校准，重渲某场后要同步。
- 颗粒很吃码率：上集 4:34 的母版是 605 MB（约 17.7 Mbps）。预留硬盘，并另出分享版。
- 上集分享版 720p、约 430 kbps，主要用于快速过片。判断像素细节要看母版。

## 9. QC 脚本和上集读数

```
python3 scripts/qc.py 成片.mp4 输出目录
```

- 输出：联系表、响度、短时最响和最静的位置、近静止比例、连续没动的段。
- 方法：低分辨率灰度，每半秒取平均，比较相邻两块。单帧差分不行：颗粒的噪声底约 .4–.6，比人物微动还大。
- 要量母版。分享版压缩后帧差偏低。
- `--left 0.36` 只量右侧主画面。手机戏打字时，全画面看着在动，主画面可能没动。

**上集通过版的读数（只作参照，不是合格线）：**

| 项 | 读数 |
|---|---|
| 时长 | 273.83 s |
| 响度 | −14.0 LUFS，LRA 8.5，真峰值 −0.1 dB |
| 近静止（右侧 64% 画面） | 18.9%，阈值 0.6 |
| 连续 ≥ 2.5 s 没动 | 1:48 手机戏 3.5 s；4:05 手机戏 3.5 s；2:28 2.5 s |
| 最静 | 4:27.7，短时 −28.4 LUFS（高潮黑场之后） |

这个脚本是写手册时才补的，只在上集成片上跑过。制作期没有用过它，所以上集的阈值没有经过多部片子校准。
