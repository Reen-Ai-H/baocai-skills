# 细节手法：让程序化场景经得起放大看

配合 SKILL.md 第 3 节"细节预算"用。先按屏幕尺寸定级别，再在这里找做法。现成函数在 `scripts/blender/detail_kit.py`。

## 1. 题材清单：这类实拍里一定有的东西

开工第 2 步把对应清单抄进项目 README，逐条打勾。清单里的东西画面里没有，就要能说出为什么（被遮挡、太远、故意留白）。

**城市天际线 / 滨江**
- 楼：楼层带、竖梃 / 窗格（真几何）、退台、塔冠、女儿墙；每栋高度、颜色、分格都不同
- 屋顶：空调外机、冷却塔、水箱、管道、天线、避雷针、维修吊篮轨道
- 密度：前排之后还有第二、三排楼，远处楼群连成一片有起伏的"城市纹理"，不是一排孤零零的楼
- 地面层：防汛墙、栏杆、路灯、行道树、码头、趸船、浮标、岸边台阶
- 水：船只尾迹、波纹碎光、岸线反射、漂浮物；江水比湖水浑浊（颜色和透明度）
- 空气：雾里分层的远近（远处楼对比低、偏冷）

**历史建筑（石材、穹顶、柱廊）**
- 柱子：柱础、柱身收分、凹槽、柱头；檐口多层线脚、齿饰；窗套、拱心石、栏杆宝瓶
- 材质：石块分缝、雨水流痕、底部发黑、风化缺角、青铜穹顶的铜绿条纹
- 低太阳时侧逆光掠过表面才出质感：机位选太阳和墙面夹角 10–30° 的方向

**桥梁 / 钢结构**
- 构件有截面（工字钢、箱梁），不是方条；铆钉 / 螺栓排、节点板、栏杆、路灯、桥面车道
- 油漆斑驳、锈迹，逆光时桁架边缘有亮边

**船**
- 船体线型（不是盒子）、吃水线颜色分界、锚、缆桩、救生圈、舷窗、货物（集装箱有不同颜色和褪色）
- 尾迹：V 形开尔文波 + 白色乱流，不只是一块面片

**湖 / 自然**
- 植物：单叶几何、叶片透光、颜色抖动；草、芦苇、苔藓、落叶
- 岸：石头、泥、湿痕、水线；水面漂浮物、涟漪
- 远山：多层，每层有林线和岩体，不是光滑噪声

## 2. 建筑：从盒子到楼

**立面（真几何）**：`facade_tower(name, cx, cy, z0, sx, sy, h, floor_h=3.8, bay=1.6, setbacks=1, seed=…)` 生成：内凹玻璃芯 + 竖梃 + 每层楼板带 + 退台 + 顶冠 + 屋顶杂物。几百栋都能跑（每栋几千顶点）。按屏幕尺寸挑做法：

| 屏幕尺寸 | 做法 |
|---|---|
| < 40 px | 盒子即可，但要有高低、退台、颜色差；数量要多 |
| 40–150 px | `facade_tower(..., bay=3.2)` 或盒子 + 楼层带材质（Brick 纹理驱动明暗和粗糙度） |
| > 150 px | `facade_tower` 默认参数；玻璃用 `mat_curtain_glass`（每块玻璃粗糙度和亮度随机） |
| 地标 | 单独写：按真实造型 loft（扭转、收分、斜撑），立面分格跟着楼层线走，塔冠和天线做到四级 |

**风格变体**：竖向细竖梃（现代写字楼）、横向窗带（80–90 年代楼）、点式窗 + 涂料墙（住宅：`mat_weathered` + 内凹窗洞 + 空调外机挂在窗下）。至少混用三种，楼群才像真城市。

**老建筑**：柱子 = 12–16 边 loft（柱础、收分、柱头）；檐口 = 多层挤出线脚；石块缝 = Brick 纹理驱动 bump，或真几何分块；底部 1–2 m 加 AO 脏污。**窗洞里必须有玻璃面**（内凹 0.3–0.6 m），墙是实心的：只挖洞不放玻璃，clay 和俯视角下整面墙会变成透空的"鸡蛋格 / 脚手架"（上海蓝调第一阶段）。从高处往下拍时，还要检查楼顶和背面是不是封闭的。

**倒角**：`bevel_all(width=0.03)`。不同尺度：楼 0.05–0.1 m、家具 / 构件 0.01–0.02 m、植物不倒角。

**地标要"一眼认出"**（上海第二轮：qa 全 OK，但上海中心是平顶圆柱、东方明珠像普通电视塔，一看就假）：
- 开工前写下这栋楼的**识别特征**（3–5 条，按剪影 → 结构 → 灯光排序），逐条做、逐条验。例：上海中心 = 圆角三角截面连续扭转约 120° + 一条螺旋上升的 V 形凹槽 + 斜切上升的塔冠（一侧低一侧高）；东方明珠 = 三根粗柱 + 三根斜撑 + 下大球 + 上球 + 顶部太空舱小球 + 分节天线；环球金融中心 = 梯形开口；金茂 = 层层收分的宝塔顶。
- **剪影检查**：只留这栋楼，纯黑剪影渲一张（本片最大那镜的焦段和尺寸），和实拍剪影并排看。剪影不对，加多少窗格都没用。
- **遮挡检查**：clay 图里看地标脚下 / 身前有没有别的楼正好挡住，并且读起来像它的"底座"或"一部分"。用相机射线（`scene.ray_cast` 从相机打向地标的几个高度）列出挡在前面的对象，移走、压低或换窄的。只按"离地标多少米以内剔除"不够：远处的楼也会在视线上叠上去。
- 沿扭转面的竖梃、楼板线要**连续**：分段生成时每段的扭转角要首尾对上，否则 1:1 下会看到悬空、错位的"滴落线"。

## 3. 密度与散布

- `instance(src, placements)` 共享网格，几千个也不爆内存；也可以用几何节点 Instance on Points（更快，适合上万）。
- 散布规则：泊松盘距离 + 按区域密度图（离岸近的密、远的疏）+ 随机旋转缩放；落地用射线求高度。
- 城市分层：前排（模型细）→ 中景（`facade_tower` 简化参数）→ 远景（盒子 + 材质，数量 200+）。远景可以做成"城市地毯"：在一块平面上按网格撒不同高度的盒子。

## 4. 材质

- 永远不要单色 Principled：至少加噪声色差（±5–10%）、粗糙度变化、AO 脏污（`mat_weathered` 就是这个模板）。
- PBR 贴图优先：`python scripts/tools/fetch_polyhaven.py texture concrete_wall_008 2k assets/tex/` → `mat_pbr_folder("concrete", "assets/tex/concrete_wall_008")`（Box 投影，不要 UV）。
- 玻璃：低粗糙 + 金属感 + 每块随机（`mat_curtain_glass`），或真 Glass + 室内假墙（近景）。看得到反射天空和对面楼，才像玻璃。
- 金属：粗糙度 0.3–0.5，加划痕 / 锈的噪声遮罩。
- 水：法线噪声用世界坐标、凹凸随距离衰减（近 0.6 → 远 0.03）；城市江水基色偏黄绿灰，透明度低。
- HDRI：Poly Haven 的日出 / 黄昏 HDRI 做环境光和反射，比纯 Nishita 天空多出云和地面反射，玻璃幕墙一下子就"活"了；太阳仍用太阳灯控方向。

**城市蓝调 / 夜景（程序化最占便宜的题材）**：几千扇亮着的窗本身就是高频细节，楼的几何简单一些也不显，水面倒影把细节再翻一倍。做法：
- 窗灯：按"楼层 × 开间"给每格一个随机值（用对象坐标 floor() 做哈希），亮灯比例 20–60%（写字楼高、住宅低），色温 2700–4500 K 混用，少量冷白的办公室灯；亮度 ±50% 抖动。**不要整栋楼全亮或全暗**，也不要排成规则图案。
- 地标有自己的灯光"签名"，要做对：比如东方明珠的球体轮廓灯、上海中心的塔冠和竖向灯带、外滩老建筑的暖黄泛光。灯光签名比形状更容易认。
- 天空：日落后 20–35 分钟，天空还有蓝，楼的剪影和天空分得开；全黑夜景天空和楼糊成一片，反而少细节。
- 水面：粗糙度低 + 细波纹法线 → 灯光被拉成长条倒影；倒影的长度和碎裂程度是"真不真"的第一眼。
- 曝光：灯不要过曝成白块，窗格里要能看见颜色和明暗；用 AgX，高光留余量。
- **窗灯别做成"拼布"**（上海蓝调终版）：为了让 2 km 外的窗 ≥ 2 px，把亮格放大到 3.6 × 7.4 m、对比拉满，结果每栋楼都是大块米黄 / 黑的棋盘，比灰麻点更假。远处宁可亮格小一些、亮度低一些，让它们融成"一层暖光 + 少量更亮的格子"；成块亮按**整层或半层**走（办公楼加班是一层一层亮的），不是随机方块。另外，大面积"玻璃反天空"在调色后容易变成一根奶白色柱子，要在成片（调色后）上看，不是只量母版的中位数。

## 5. 植被

- 单叶要有几何（四边形 + 弯曲），颜色 ±3% 抖动，Translucent 混合透光。
- 树：枝干 loft + 叶簇实例；远景树用卡片或团块。Poly Haven 有 CC0 树模型，近景优先用。
- 草 / 芦苇：几何节点或粒子毛发；贴水岸一圈，比一条干净的岸线真实得多。

## 6. 数据源（真实地点）

- **OpenStreetMap**：建筑轮廓 + `height` / `building:levels`。Blender 插件 blosm 直接导入；或者 overpass API 拉 GeoJSON，用 Python 挤出。地标仍手工精做。
- **DEM 地形**：SRTM / Copernicus 30 m，转高度图后做 displacement 或直接 from_pydata。
- 太阳方位用真实日期时间计算（`pysolar` 或天文公式），写进 README。

## 7. 什么时候可以少画

- 真的远（< 40 px）、真的被雾或剪影吞掉的部分可以只做一级。
- 但"可以少画"要由**相机和距离**决定，不由"做起来麻烦"决定。判断时看 clay 图：clay 里主体是积木，光和雾怎么调都救不回来。
