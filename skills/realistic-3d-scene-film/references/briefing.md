# 怎么给 agent 写需求：要氛围，也要细节

适用：用户给 DeepSeek、Codex、Claude 等任何编程 agent 下需求；或者你把任务拆给子 agent。上海那次需求里有大量"剪影""雾里虚掉""背景虚化"，却没有一句可检查的细节要求，结果 agent 把全部精力花在雾和光上。

## 原则

1. **每个镜头同时写"氛围"和"必须看得清的东西"。** 例："逆光剪影"后面要跟"剪影轮廓里能看出塔冠、天线、屋顶设备"。
2. **给验收标准，不只给形容词。** "极致审美"不可检查；"每张图 `qa_detail.py --mask` 判定 OK，并附三块 1:1 裁切"可检查。
3. **先灰模、再细节、最后氛围**，并要求每一步给图。
4. **要求说实话 + 先修再交**：列最弱的镜头和原因，修完再交，修不了要说为什么。
5. **允许用素材**：Poly Haven（CC0）的 HDRI、贴图、模型，OpenStreetMap 楼块。
6. 长任务里 agent 会忘规则：把验收标准放在需求**末尾**再重复一次，并在每个阶段结束时要求它对照检查。

## 模板（复制后替换尖括号）

```
用 /realistic-3d-scene-film 这个 skill（先完整读 SKILL.md 和 references/detail.md）。

【这一刻】<地点>，<日期 时刻>，太阳高 <x>° 在 <方位>，<天气 / 雾>。不要人物。
【题材清单】先按 references/detail.md §1 列出这类实拍里一定有的细节，写进项目 README，再开工。

【镜头】每镜写：焦段、主体、氛围、必须看得清的细节
01 <焦段>：<主体和构图>。氛围：<…>。必须看得清：<结构 / 材料 / 小物件>。
02 …

【做法要求】
- 顺序：灰模机位 → 细节层（按 SKILL.md §3 细节预算算每个主体的屏幕像素，做到对应级别）→ 材质 → 光雾。每一步给我一张图。
- 可以下载 Poly Haven 的 HDRI / PBR 贴图 / 模型，可以用 OpenStreetMap 楼块数据。
- 所有硬边加倒角；同类物体（楼、树、船）要有随机差异，数量做到真实量级。
- 雾只做氛围，不能用来盖住没做的细节；长焦镜头只拍细节撑得住的对象。

【验收（每张图都要满足，交付时附结果）】
1. detail_kit.py -- mask 出蒙版，qa_detail.py --mask 判定为 OK；贴出数字。
2. 自己看过三块 1:1 裁切，逐张说一句"像照片 / 像建模截图，因为…"。
3. clay 图里主体不是积木。
4. 列出最弱的 2 个镜头和原因，先修再交。
```

## 已经交了一版、细节不够时的追加消息（示例）

```
这组九宫格的问题是细节严重不足：楼都是平面盒子，雾和逆光把它们糊成剪影，长焦镜头把盒子放大到半个画面。
请先读更新后的 SKILL.md（重点 §3 细节预算、§6 细节体检）和 references/examples/shanghai-postmortem.md，然后：
1. 对现在的 9 张图跑 mask + qa_detail.py，把每张的 verdict 和 clay 图给我，确认问题在几何。
2. 按 postmortem 的"应该怎么做"重做楼群和地标（OSM 楼块 + facade_tower + 地标精做 + 地面层），全部倒角。
3. 先出 01 和 03 两张无雾 clay + 成片，给我看，过了再做其余七张。
4. 每张交付前 verdict 必须是 OK，并附三块 1:1 裁切的自评。
```

## 用户要"快一点"时（快速模式）

用户说"别一直迭代 / 质量可以降一点、内容要齐"时（上海蓝调，2026-11-19）：
- 把剩下的阶段合成一条消息，一次做完、直接出终版，中间不停下等验收。
- 每一项**最多一次**低采样预览（50% / 32 spp），看完就往下走；修不好的小问题用最省事的办法处理（移出画面、放进阴影、调暗），汇报里写一句。
- 内容清单不砍（地标、灯光、倒影、船都要有），砍的是精度：1920 宽、96–128 spp + 降噪，体检跑一次，不 OK 也先交并写明原因。
- 给一个总时长目标（例如 40 分钟），并要求先估渲染时间，超了就降采样。
- 验收人这时只看终版：先给用户看图，再列"还能改进的地方"，由用户决定要不要再来一轮。
