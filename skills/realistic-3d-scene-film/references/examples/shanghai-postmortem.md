# 《上海·晨》复盘：为什么细节严重不足（2026-11-18）

执行：DeepSeek（dsh，`deepseek-v4-flash-vision-exp`），用的是本 skill 的旧版。九张图在 `westlake_dawn/renders/sh/final/`。用户评价："生成图片质量这么低……在细节上特别缺失"。

## 现象

- 陆家嘴 50 栋填充楼、外滩 40 栋老建筑都是**平面盒子**；楼窗只是一个很弱的材质格子（1920 宽下看不出来）。
- 东方明珠、上海中心、环球金融中心只有大形 loft，没有立面分格、塔冠、天线细节。
- 9 张里 8 张靠浓雾 + 逆光把楼变成剪影或白雾。02、06、07 三张用 135–200 mm 长焦正对着盒子，盒子被放大到半个画面。
- 没有地面层：防汛墙、栏杆、路灯、行道树、码头都没有。
- `qa_detail.py`（带实体蒙版）测 07 镜：实体区域 69% 是平的，`verdict=GREYBOX`。clay 图（去雾去材质）就是一组积木。

## 根因（按影响排序）

1. **旧 skill 的核心句是"宁可少画、藏进雾和逆光"。** 湖景成立，城市不成立。agent 照做了：200 多步全在调雾、水、天空、曝光，没有一步在加几何细节。
2. **没有细节预算。** 没人算过 200 mm 下一栋楼占多少像素，长焦镜头把最简陋的部分放到最大。
3. **自查只看缩略图。** agent 看了 6 次 640×360 每格的九宫格、0 次 1:1 裁切，然后宣布"九镜都立住了"。
4. **把不足写进 README 就交付**（"03 比较空""填充楼像纸板"），没有修。
5. **用户 prompt 也在推向剪影**：九个镜头描述里反复出现"只剩剪影""雾里虚掉""背景虚化"，却没有一句要求可见的结构细节；agent 拿到的是"氛围"指令，没有"细节"验收标准。
6. **没用任何外部素材**：没有 HDRI、PBR 贴图、OSM 楼块；全部 from_pydata 手摆。
7. 模型是 flash 档 + 实验视觉，长任务里对细节的自我批评能力弱，更需要硬性检查工具兜底。

## 应该怎么做

1. 题材清单（`detail.md` §1 城市 / 历史建筑 / 桥 / 船）抄进 README。
2. 楼群：OSM 拉陆家嘴和外滩的轮廓与高度（几百栋），前排和地标用 `facade_tower` + 手工精做，远景用盒子地毯；全部 `bevel_all`。
3. 地标做到四级：上海中心 120+ 层楼板线随扭转、幕墙分格、顶部开口；东方明珠的球体分格、斜撑截面、天线分节。
4. 外滩：柱廊、檐口线脚、石材 PBR、铜绿穹顶；05 镜的机位改到太阳和立面夹角 15–25° 的方向（侧逆光掠过石头），而不是把它拍成剪影。
5. 加地面层：防汛墙 + 栏杆 + 路灯 + 行道树 + 码头；江面加航标、浮标、几条不同的船。
6. 日出 HDRI 做环境，玻璃幕墙才有天空和对岸的反射。
7. 雾按镜控制在 `veiled ≤ 0.30`；长焦镜头只拍细节撑得住的对象。
8. 每张图跑 `mask → qa_detail.py`，看三块 1:1 裁切，`verdict=OK` 才交。

## 第二轮（2026-11-19，按新 skill 重做 01 / 03）

用新 skill + 分阶段 brief 后，15 分钟内：OSM 3239 栋楼、真实岸线、git 管版本、色带查因（16-bit 母版没有台阶，问题在转 8-bit）。01 `qa` 从 THIN 到 OK（detail_med 4.8 → 14.4）。进步是真的，但独立验收又发现了四类**工具量不出来**的问题，已写进 skill：

| 问题 | 为什么工具没报 | skill 里的对策 |
|---|---|---|
| 上海中心平顶、看不到 V 形凹槽；东方明珠只有一个球加一根杆 | 有窗格就有边缘，detail_med 很高 | `detail.md` §2 地标识别特征 + 剪影对比 |
| 01 塔身正下方叠了一栋更宽的楼，读起来像底座 | 它在"离地标 170 m 剔除"范围外，但正好挡在视线上 | 相机射线遮挡检查 |
| 03 "玻璃反朝阳"：机位在逆光一侧，物理上不可能；画面 89% 是平的天空 | 蒙版只量塔身，verdict OK | SKILL §4 光向检查；`qa_detail.py` 新增 `note=SPARSE` |
| 01 太阳正下方的江面没有金色光带 | 水面在蒙版外 | SKILL §4：逆光水面最亮的一条必须在太阳下方 |
| 03 竖梃分段扭转，接缝处悬空错位 | 错位的线也是"边缘" | `detail.md` §2：分段扭转首尾对齐 |

教训：**数字过关是必要条件，不是充分条件**。验收人必须对着识别特征和物理（光向、倒影）逐条看 1:1。之后改做蓝调题材（程序化城市的强项），见 SKILL §4。
