# 案例：《西湖·晨》（2026-11，湖景，效果被用户认可）

第一个用这套流程做完的片子：英雄图 → 8 镜 40 秒纪录短片 → 九宫格和小红书 → three.js 重渲。参考脚本 `scripts/blender/build_westlake.py`、`doc_shots.py` 就是它。原项目（.blend、渲染帧、声音、成片）在仓库 `westlake-3d/`。

湖景为什么"藏进雾里"能成立：主体（塔、桥、柳、荷、鸟）本来就以剪影和留白为美，近景（荷叶水珠、柳丝、蜻蜓）都做到了三、四级细节。换成城市或建筑，这一招不能照搬（见 `shanghai-postmortem.md`）。

## 用户反馈 → 做法

| 用户原话 / 反馈 | 落到做法上 |
|---|---|
| "尽可能展现你的极致审美，超强的氛围感"（第一句需求） | 低太阳 + 晨雾 + 逆光 |
| "人物有假人感……可以只做风景，有一些动物、植物，就不要有人物了" | 默认不放人，连远处的摇橹人也去掉 |
| 白鹭、野鸭近看像"摆件"（审片时自查出来） | 动物上长焦（135–200 mm）、逆光、在画面里小、远 |
| 石塔孔洞亮着像"眼睛" | emission ≲ 1；任何"像脸"的排布都要查 |
| "导演剪辑手法，类似纪录片的感觉" | 硬切、焦段变化、拉焦、有一个"事件"、真实环境声、片头地点字幕，不用配乐 |
| 九宫格"效果蛮好" | 每个镜头单独构图成立 |
| 看完 Cycles 和 three.js 九宫格对比："效果上还是 Blender 更好，特别是静态图像，非常自然" | 图像一律 Cycles，three.js 只辅助做视频 |

## 分镜（8 镜 40 秒，24 fps，960 帧，帧区间在 `doc_shots.py` 的 `SHOTS`）

| 镜 | 内容 | 焦段 / 光圈 | 手法 |
|---|---|---|---|
| S1 | 荷叶水珠微距 | 100 mm f/3.2 | 慢推，开场静 |
| S2 | 湖面大全景，白鹭低飞 | 45 mm | 推进，地点字幕 |
| S3 | 雾里的塔 + 鹭群 | 135 mm | 硬切 + 远处钟声 |
| S4 | 白鹭伫立，鱼咬水面两次 | 200 mm，30 m 外 | 事件 + 涟漪 |
| S5 | 荷花 → 拉焦到花苞上的蜻蜓 | 90 mm f/2.8 | 变焦 + 推近 |
| S6 | 野鸭划过日光水道 | 200 mm，42 m 外 | 尾迹 |
| S7 | 柳丝前景 → 拉焦远景 | 85 mm f/2 | rack focus 2.6 → 70 m |
| S8 | 收尾大全景后拉 | 35 mm | 片尾片名 |

## 参考机器和耗时

RTX 4060 Laptop 8 GB，Windows，Blender 5.2.1。1080p 64 spp ≈ 30 s/帧（960 帧 8 h）；75% + 32 spp + 降噪 8.5–25 s/帧（约 4.5 h）。OptiX 内核在这台机器上报过 `OPTIX_ERROR_INTERNAL_COMPILER_ERROR`，用 CUDA 渲染 + OptiX 降噪器正常。

## 时间线

| 阶段 | 内容 | 结果 / 用户反馈 |
|---|---|---|
| v1 | 从 game-look-micro-film 转向写实 3D；Blender 程序化西湖（断桥、雷峰塔、三潭、柳、荷、白鹭、摇橹人），英雄图 + 8 s 动画 | "视频里的人物有假人感" |
| r2 | 去掉所有人物；8 镜 40 s 纪录片；动物改长焦逆光；真录音声音；字幕 | 预览中自查：白鹭、野鸭近看像摆件 → 重新调度；石塔孔洞像眼睛 → 调暗 |
| 渲染 | 1080p 64 spp ≈ 30 s/帧，8 h | 用户选"分辨率和采样一起降"：75% + 32 spp → 约 4.5 h |
| 夜间 | night.sh 补帧 + 出片 + 用户授权的延时关机 | 02:36 渲完，02:52 出片，送片后关机 |
| 小红书 | 九宫格 + 单图 + 文案.md | "九宫格的效果蛮好" |
| three.js | 同场景导出到 three.js 重写光照材质；九张 2560×1440 静帧 5.5 min；10 s 效果视频 18.5 min | 用户问效果/效率/适用性对比 → 见 `references/threejs.md` |
| 结论 | 用户看完对比 | "效果上还是 Blender 更好，特别是静态图像，非常自然" → 图像用 Blender，three.js 只辅助做视频 |

## Cycles vs three.js 实测像素（S2 第 109 帧，AgX 后 0–1）
调参前 three.js 天空暗约 15%、偏粉；桥偏亮；日光水道偏暗。调参后（暖地平线、天空增益 1.3、环境光 0.55、GGX 加宽、饱和 1.18）肉眼对比基本一致。三处残余差异：S1 叶色（绿 vs 金褐）、S4/S6 日光倒影更宽更亮、倒影更清晰。
